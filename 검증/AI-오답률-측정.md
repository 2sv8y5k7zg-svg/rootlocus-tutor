이 파일과 정답표, 질문 문장은 `python3 tools/make_benchmark.py`가 tests/expected.json(sympy 기준 정답)에서 만듭니다. 정답표의 숫자는 손으로 고치지 않습니다.

## 정답표 검증 방법
```
pip install sympy numpy
python3 tools/check_answer_table.py          # 30문제 전체
python3 tools/check_answer_table.py T17 T29  # 일부만
```
- 정답표의 '전달함수' 칸만 읽어 `tools/reference.py`(sympy + numpy, 엔진과 코드 공유 없음)로 다시 계산하고, 항목 1~5와 실수축 구간 숫자가 정답표에 들어 있는지 비교합니다. 끝에 `결과: 30/30 일치`가 나오면 통과입니다.
- 문제 정의는 tests/problems.json(T01~T32), 기준 정답은 tests/expected.json에 있습니다. 문제를 바꾸면 `python3 tools/reference.py` → `node tests/run-tests.js` → `python3 tools/make_benchmark.py` → `python3 tools/check_answer_table.py` 순서로 다시 만듭니다.
- 2026-11-14 KST 확인: 정답표 30/30 일치, 엔진 검사 34/34 문제·514/514 항목 통과.

## 무엇을 재나
근궤적 문제 30개를 일반 AI에 같은 문장으로 묻고, 항목별로 맞았는지 기록합니다. 결과는 나온 그대로 씁니다. AI가 많이 맞히면 그 숫자를 그대로 적고, 근거 문장을 "그림이 틀린다" 쪽으로 바꿉니다.

## 측정 조건 (모든 문제에 똑같이)
- AI마다 서비스 이름, 모델 이름, 요금제(무료/유료), 측정 날짜를 기록 표에 적는다.
- 문제마다 새 대화를 연다. 앞 문제의 답이 영향을 주지 않게 한다.
- 아래 질문 문장을 그대로 붙여 넣고, 전달함수 줄만 바꾼다.
- 첫 번째 답만 채점한다. 다시 묻거나 힌트를 주지 않는다.
- 답 화면을 캡처해 `문제번호_AI이름.png`로 저장한다(본선 질의응답 증빙).

## 질문 문장
```
다음 개루프 전달함수의 근궤적을 분석해 주세요.
조건: 음의 피드백, K ≥ 0

G(s)H(s) = (여기에 전달함수)

아래 항목을 값으로 답해 주세요. 해당 사항이 없으면 "없음"이라고 써 주세요.
1) 점근선의 개수, 중심, 각도
2) 실수축 위 이탈점·진입점의 위치(s 값)
3) 근궤적이 허수축과 만나는 점의 ω와 그때의 K
4) 폐루프 시스템이 안정한 K의 범위
5) 복소 극점의 출발각 (복소 영점이 있으면 도착각)
6) MATLAB의 rlocus 결과처럼 근궤적 그림을 그려 주세요.
```

## 채점 기준
- 항목 1~5는 O / X / −(해당 없음)로 적는다. 숫자는 정답과 2% 또는 0.02 이내면 O, 각도는 1° 이내면 O.
- 정답이 "없음"인데 AI가 값을 지어내면 X. 정답이 있는데 "없음"이라고 하면 X.
- 4번은 경계 숫자가 맞으면 O. K = 0을 범위에 넣었는지는 따지지 않는다.
- 5번은 위쪽 복소 극점(영점)의 각 하나만 맞으면 O. −45°와 315°처럼 360° 차이는 같은 답이다.
- 6번 그림은 세 가지를 본다: 실수축 구간이 정답표와 같은가 / 가지 수와 점근선 방향이 맞는가 / 허수축을 넘는지 여부가 3번 답과 같은가. 셋 다 맞으면 O, 하나라도 틀리면 X, 그림을 못 그리면 "그림 없음".
- 문제 판정: 해당하는 항목 1~5가 모두 O면 "정답", 하나라도 X면 "오답". 그림은 따로 센다.
- PPT에 적는 숫자: 문제 오답률(오답 문제 수 / 전체), 항목 오답률, 그림 오답률. 측정 조건을 함께 적는다.
