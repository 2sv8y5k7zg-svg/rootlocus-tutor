- 익명으로 받는다. 이름·학번·연락처는 묻지 않는다(대회 규정: 실제 개인정보 사용 금지).
- 문항은 답을 유도하지 않게 썼다. 결과는 나온 그대로 PPT에 "팀 설문, 응답 n명, 2026-11"로 적는다.
- 구글 설문지에 아래 문항을 그대로 옮긴다. 8번만 선택 문항, 나머지는 필수.

## 안내 문구
제어공학 근궤적 학습 도구를 만드는 팀(2026 안양대 AI 경진대회)입니다. 1분이면 끝나는 익명 설문입니다. 응답은 대회 발표자료에 통계로만 쓰입니다.

## 문항
1. 근궤적 문제를 손으로 풀어 본 적이 있나요?
   - 있다 / 없다 (없다면 설문 종료)
2. 근궤적 과제·시험 문제는 주로 어떤 형태로 나오나요?
   - 전달함수 식으로 / 블록선도로 / 둘 다
3. 근궤적 한 문제를 손으로 끝까지 푸는 데 보통 얼마나 걸리나요?
   - 5분 미만 / 5~10분 / 10~20분 / 20분 이상
4. 푼 답이 맞는지 주로 어떻게 확인하나요? (모두 선택)
   - 교재 답지 / MATLAB 등 프로그램·웹 도구 / 친구·조교·교수님께 질문 / ChatGPT·Gemini 등 AI / 확인하지 못하고 넘어간다 / 기타
5. 정답과 내 답이 다를 때, 어느 단계에서 틀렸는지 주로 어떻게 찾나요? (모두 선택)
   - 처음부터 다시 푼다 / 답지·도구의 풀이와 한 줄씩 비교한다 / 친구·조교·교수님께 질문 / AI에 질문 / 찾지 못하고 넘어간다
6. 틀린 단계를 찾는 데 보통 얼마나 걸리나요?
   - 5분 미만 / 5~10분 / 10~20분 / 20분 이상 / 못 찾는 경우가 많다
7. AI(ChatGPT, Gemini 등)에 근궤적 문제를 물어본 적이 있다면, 답이 어땠나요?
   - 물어본 적 없다 / 틀린 적이 없었다 / 가끔 틀렸다 / 자주 틀렸다 / 맞는지 판단할 수 없었다
8. (선택) 근궤적에서 가장 자주 틀리는 단계는 무엇인가요?
   - 블록선도를 식으로 정리하기 / 실수축 구간 / 점근선 / 이탈점·진입점 / 출발각·도착각 / Routh 표·허수축 교차 / 전체 그림 그리기

## PPT에 쓸 숫자

- 6번에서 10분 이상 또는 "못 찾는 경우가 많다" 비율
- 2번에서 블록선도가 포함된 비율
