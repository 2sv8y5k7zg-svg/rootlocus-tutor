- 2026-11-14: 무료 웹 도구 RLocusGui가 근궤적·규칙별 과정·K 변화를 이미 보여 준다는 것을 팀이 직접 써 보고 확인. 그쪽에 없는 것(블록선도 입력, 내 답 대조, 틀린 이유 안내)이 우리 차별점이므로 이 항목을 필수로 올린다.
- "내 답 확인"에서 틀린 답이 나오면, 팀이 정리한 흔한 실수 목록으로 후보를 찾고 AI가 "영점 합을 빼지 않았나요?"처럼 되묻는다.
- 흔한 실수 목록(팀 작성): 중근을 1개로 셈, arctan 사분면 보정 누락, Σ영점 부호, 점근선 개수 n−m 착오, K < 0 후보를 이탈점으로 인정, 경계 K를 안정 범위에 포함.
- 팀 코드: 각 실수를 엔진 값에 적용해 "그 실수를 했을 때 나오는 답"을 미리 계산 → 학생 답과 가까운 실수를 AI에 후보로 전달. AI는 후보 중에서만 고르고 단정하지 않는다.
- 완료 기준: 실수 유형별 예시 답 10건 이상에서 후보가 맞게 잡히는지 기록.
