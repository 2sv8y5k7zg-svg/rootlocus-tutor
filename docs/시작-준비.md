# 작업 시작 준비 (노트북에서, 순서대로)

작성: 2026-11-06 KST. 모두 무료입니다. 계정 비밀번호와 API 키는 Claude 채팅에 붙여 넣지 마세요.

## 1. 동작 확인 (5분, 설치 없이)
- [ ] 압축을 풀 폴더 정하기 (예: C:\dev\rootlocus-tutor). 한글·공백이 없는 경로가 안전합니다.
- [ ] `dist\rootlocus-tutor.html`을 더블클릭 → 예제를 눌러 학습 시작 → 1~9단계까지 넘겨 보기
- [ ] 첫 화면의 "AI 연결 없음: 정적 힌트로 동작"은 정상입니다. AI는 배포(할 일 2번) 뒤에 켜집니다. AI까지 보려면 claude.ai의 미리보기(근궤적 AI 튜터)를 엽니다.

## 2. 설치
- [ ] Claude 데스크톱 앱 → 로그인 → **Code 탭** 확인. 윈도우에서 Code 탭이 안 되면 앱 안내대로 Claude Code를 따로 설치합니다.
- [ ] Git (git-scm.com). 계정 없이 이 폴더 안에서 쓰는 '되돌리기 기록'용입니다. 설치 옵션은 기본값.
- [ ] Node.js LTS (nodejs.org). 엔진 검사와 Cloudflare 배포 도구에 필요합니다.
- [ ] 파이썬 3 (python.org, 설치 첫 화면에서 PATH 추가 체크). 화면을 고친 뒤 한 파일로 다시 묶는 `tools/build.py`에 필요합니다.
- [ ] (선택) `pip install sympy numpy control matplotlib playwright` — 기준 정답·비교 그림을 다시 만들거나 화면 자동 점검(`tools/smoke.py`)을 돌릴 때만 필요합니다.

## 3. 계정 (배포 전까지만 있으면 됨)
- [ ] Cloudflare 무료 계정 (dash.cloudflare.com)
- [ ] Google AI Studio에서 Gemini API 키. **메모장에만 두고 아무 데도 붙여 넣지 않습니다.** 배포할 때 직접 입력합니다.
- [ ] GitHub (나중에): 노트북 고장 대비 백업, 친구와 같은 코드로 작업, 본선 소스코드를 저장소 링크로 낼 때 필요합니다. 배포 무렵 연결을 권하고, 늦어도 본선 제출(2026-12-01(화) 18:00 KST) 전.

## 4. Claude Code에 처음 보낼 말 (복사해서 사용)
```
CLAUDE.md와 docs/할일.md를 먼저 읽어 줘.
GitHub은 나중에 연결할 거라, 지금은 이 폴더에서 git init과 첫 커밋만 해 줘(push 없음).
그다음 node tests/run-tests.js가 225/225 통과하는지 확인하고 결과를 짧게 알려 줘.
그 뒤에는 할 일 순서대로 진행하되, 삭제·덮어쓰기·설치·배포·키 입력 전에는 꼭 나한테 먼저 확인받아.
```
