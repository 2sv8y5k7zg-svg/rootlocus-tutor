# 근궤적 스튜디오 화면 개편과 검증

## 바뀐 사용 경험

- 밝은 회백색 바탕과 청록색 강조, 극점·영점·근궤적의 의미 색상 유지. 다크 테마 제공.
- 식을 입력하면 기존 계산 엔진으로 전체 근궤적을 미리 보여 줌. 장식용 그래프가 아님.
- 데스크톱은 학습 순서 / 그래프 / 풀이 패널, 태블릿은 가로 단계 메뉴 / 그래프와 풀이, 모바일은 세로 배치.
- 풀이와 힌트·연습을 탭으로 구분. 기본 힌트는 AI 연결 없이 사용 가능.
- 단계 전환과 그래프 움직임, 재생·일시정지·현재 단계 건너뛰기, 움직임 줄이기 설정 제공.
- 모바일에서 K 슬라이더를 그래프 바로 아래로 이동. K 빠른 이동 시 직선 잔상 초기화.
- K=0이 테마 변경이나 단계 재방문 때 임의 기본값으로 바뀌던 문제 수정.
- 입력 처리 대기 중 시작 버튼 비활성화. Enter 시작 시 현재 입력을 재검증.
- 모달의 Escape·Tab 이동 보완. viewport/UTF-8/lang 선언. 외부 글꼴 의존 제거.

## 계산과 표기

계산 엔진 `js/`와 기준 정답은 수정하지 않았음.

- 1단계의 G(s)H(s) 표기를 입력 화면과 맞춤: 이 화면에서는 이미 K를 포함하므로 특성방정식은 `1 + G(s)H(s) = 0`, 곧 `D(s) + K N(s) = 0`.
- 점근선이 하나면 중심값은 풀이에 남기되 중심 점은 숨기고 실수축 방향임을 설명.
- 진입점·인입점 병기. 어두운 테마의 흐린 글자 대비 보완.
- 새로운 AI API·키·서버는 추가하지 않았음. 자유 질문 AI가 연결되지 않았음을 명시.
