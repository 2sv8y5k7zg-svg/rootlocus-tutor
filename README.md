## 풀이 순서 (수업에서 푼 방식)
1. 특성방정식 1 + K·N(s)/D(s) = 0 → D(s) + K·N(s) = 0
2. 극점(K = 0 출발점)·영점(K → ∞ 도착점)·가지 수
3. 실수축 구간: 시험점 오른쪽의 실수 극점·영점 개수가 홀수 (중근은 겹친 수만큼)
4. 점근선: 각 (2k+1)·180°/(n−m), 중심 (Σ극점 − Σ영점)/(n−m)
5. 이탈점·진입점: D′N − DN′ = 0, K = −D/N이 양수인지 확인 (언덕 꼭대기 = 이탈점, 골짜기 바닥 = 진입점)
6. 출발각·도착각: θ = 180° + Σ영점각 − Σ다른 극점각 (벡터와 arctan 사분면 보정)
7. Routh 표 → 안정한 K 범위, 허수축 교차(보조방정식)
8. 근궤적 완성
9. K 변화에 따른 폐루프 극점 이동

## 지원 범위 (1차)
연속시간, 음의 피드백, K ≥ 0, 실수 계수, 분모 4차 이하, 분자 차수 ≤ 분모 차수.
극점·영점 상쇄, 분자 차수 > 분모 차수, 5차 이상, 최고차항 부호가 반대인 식(실질적 K ≤ 0)은 계산하지 않고 이유를 안내합니다.

## 확인한 범위와 한계
- 테스트를 통과한 16개 입력(정상 12, 지원 밖 4)에서만 정확성을 확인했습니다. 모든 입력에서 정확하다는 뜻은 아닙니다.
- Routh 첫 열이 항상 0이 되는 특수한 경우(ε 방법)는, 표를 그 행까지만 문자로 보여 주고 안정 판정은 폐루프 극점 직접 계산으로 합니다.
- 곡선은 화면 대각선의 0.6% 간격 이하로 이어 그립니다. python-control 결과와의 최대 차이는 0.3% 이내입니다.
