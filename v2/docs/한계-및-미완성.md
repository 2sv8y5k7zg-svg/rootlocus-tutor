## 알려진 한계
- 정확성 확인 범위: 검증 문제 36개(정상 30, 지원 밖 6)와 무작위 1,000개(자체 검증만). 모든 입력에서 정확하다는 뜻은 아님.
- T16~T34 기대값은 손 풀이지만 Claude가 작성했으므로 팀의 독립 검산이 필요함.
- Routh 특수 경우(ε, 영행)가 있으면 안정 범위는 폐루프 극점 직접 계산으로 정함(표는 보여 줌).
- 블록선도 해석은 신호 방정식을 sympy로 풀어 폐루프 T(s)를 얻는데, 이 과정에서 약분된 공통 인수(숨은 극점·영점 상쇄)는 감지하지 못할 수 있음.
- 근궤적 곡선은 화면 대각선 0.5% 간격 이하로 이어 그림. python-control 결과와 화면 대각선 0.5% 이내로 일치(모든 정상 문제).
- 손글씨 검사는 AI가 읽은 값만 채점함. 근궤적 그림 자체는 채점하지 않음(지시서 6번).
- 랜딩 페이지 오브젝트는 Canvas 2D로 그린 장식용 곡선(3D 엔진 미사용). Scene 2 전환 중간 모양은 더 다듬을 여지가 있음.
- 학습 기록은 저장하지 않음(새로고침하면 초기화). 사진은 서버 메모리에서만 처리.
