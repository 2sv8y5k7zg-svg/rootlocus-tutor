## A. 예선 PPT와 어긋난 곳 메우기

### 1. 학생 자유 질문 칸
- 예선 PPT 2장: "학생의 질문 → 질문에 맞는 설명". 지금은 힌트 버튼만 있음.
- 힌트 시트에 질문 입력 칸 → 서버 `/api/ai/ask`(새 경로) → 프롬프트에 그 단계의 엔진 값·팀 힌트를 함께 보냄 → `check_numbers`로 숫자 검사 → 실패·불일치면 팀 힌트.
- 정답을 먼저 말하지 않는 규칙은 `ai/prompts.py HINT`와 같게.
- 완료 기준: 질문 → 답이 엔진 숫자만 씀(시험 추가), AI 꺼짐·숫자 불일치일 때 팀 힌트로 동작, pytest 전부 통과, 대조표 2장 줄 갱신.

### 2. 식을 입력하는 즉시 수식·그래프 미리보기
- 예선 PPT 6장 1차 화면에 있었고 v2 입력 화면에는 없음.
- 입력이 멈추면(약 300ms) `/api/analyze`로 극점·영점만 받아 작은 s평면과 수식으로 보여 줌. 범위 밖이면 이유 한 줄.
- 완료 기준: PC·휴대폰 폭에서 입력 중 끊김 없음, 잘못된 식에서 오류 없이 안내, 대조표 6장 줄 갱신.

- 완료 기준: 화면·코드·PPT 이름이 같음, 대조표 6장 줄 갱신.
